# [Pensieve](https://pensieve.amatiasq.com)

Notes saved in your private GitHub repository. The first line of a note is its
filename; a `/` in it makes a folder and the extension picks the syntax
highlighting. Every save is a commit, so the history is git's.

## Setup

- Sign in with GitHub. The repo is created on first run; it defaults to
  `pensieve-data`. Use [`?repo=`](https://pensieve.amatiasq.com/?repo=other)
  to point to another one.
- **Install it from Chrome.** Some keyboard shortcuts are captured by the
  browser otherwise.
- Settings and shortcuts are JSON, edited in-app at
  [`/settings`](https://pensieve.amatiasq.com/settings) (`CMD+,`).
- Notes opened at least once stay readable and editable offline.

## Caveats

- Switching devices doesn't refresh the note list until you reload.
- Opening a note takes a few seconds on mobile, cause unknown.
